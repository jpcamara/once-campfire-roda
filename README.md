# Campfire on Roda

[Campfire](https://github.com/basecamp/once-campfire) reimplemented on Roda and Sequel, running on
Falcon. It's built to the same bar as the [Sinatra](https://github.com/jpcamara/once-campfire-sinatra)
and [Rage](https://github.com/jpcamara/once-campfire-rage) versions: from the outside it behaves like the
Rails app, checked with the parity harness from DHH's
[once-campfire-rust](https://github.com/basecamp/once-campfire-rust).

Work in progress: verification and benchmarks are running. This README will carry the results.
